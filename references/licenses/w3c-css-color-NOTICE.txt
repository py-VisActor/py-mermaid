The Python implementation in rendering/labels/controls/color_values.py reformulates
the conversion equations and matrices for native static color input initial-state
normalization. No JavaScript engine or browser is used at runtime. Existing pure
Mermaid color names and channels are reused. Source snapshots, original repository
license applicability and download SHA records are in references/html-host-semantics.json.
