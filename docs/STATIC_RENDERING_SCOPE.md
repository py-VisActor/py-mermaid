# 全项目范围：仅静态渲染

2026-11-05，用户明确：**所有模块忽略交互逻辑，只考虑静态渲染。** 本规则适用于全部图种、共享模块、API、导出、依赖选型和验收，覆盖旧计划中要求迁移交互逻辑或交互元数据的内容。机器策略见 [static-rendering-scope.json](../references/static-rendering-scope.json)。

## 保留与排除

| 类别 | 当前范围 |
| --- | --- |
| 语法与静态语义 | 保留图种、节点/边/分组、文字/公式、关系、方向、静态配置、布局约束、错误位置；在对应语法扩全时安全识别交互声明，忽略其执行语义，不破坏同一输入的静态内容 |
| 静态画面 | 保留 shape、marker、路径、曲线、样式、主题、文字格式、图标/图片、图标题、seed、遮挡/裁剪和可读性 |
| 静态输出 | PNG、SVG、PDF 及后续明确开放的静态格式；核对实际图形、文字、字体/路径、尺寸、背景和资源 |
| 事件与行为 | 排除 click、callback、bindFunctions、事件注册/分发、hover/focus 状态切换、tooltip 弹出、导航/链接激活、拖拽/缩放/选择/编辑和命中测试 |
| 交互表示 | 不要求交互元数据、可点击区域、链接 annotation、callback 描述、事件宿主、浏览器 DOM/无障碍交互树；既有纯值字段不因本次范围决策而删除或破坏兼容 |
| 动画 | 排除播放、时间轴、帧序列及动态状态更新；保留其静态初始外观，参考采集固定初始时刻 t=0，记录实际初始 dash/线宽/marker/颜色等静态状态 |
| 安全 | 保留输入清洗、资源路径/URL策略、离线限制、大小/数量上限及脚本拒绝；忽略交互不等于执行脚本、读取任意文件或下载远端资源 |

图标题、标签和可见说明文字仍须绘制。`accTitle/accDescr` 等既有纯值数据可以保留，但不会为屏幕阅读器行为、ARIA/DOM 结构或额外可访问性导出协议建立交付门槛。链接或动画声明若影响静态初始样式，只保留这部分可见效果，不实现其行为。

本次是范围与文档变更，不宣称旧切片 parser 已支持全部 click/动画等语法；相应静态语法扩全仍按任务实现和验证。

## SVG/PDF 的含义

Canvas 的 SVG/PDF 导出按静态视觉输出验收：图形/文字/字体或轮廓/图片、层叠、尺寸、透明与背景正确。无需另建带链接、回调、动画、DOM 可访问性树或交互宿主的 Mermaid SVG 实现。可见文字与必要静态导出结构仍属于验收范围。

因此 F01.4 删除“交互与动画宿主”“链接/回调输出协议”等工作项；ELK、曲线、新形状、手绘、资源和数学排版等静态能力保留。

## 清单与验收

- 完整上游源码、依赖树和 spec 索引继续保留，不能改动来源事实。纯交互行为标为 `excluded_by_static_scope`，这是用户明确排除，既不计未完成迁移，也不计功能通过。
- 静态与交互混合条目按断言拆分。例如 links/interaction/security 中的事件/导航排除，输入和资源安全保留；动画播放排除，其静态初始画面保留。
- A/B 只检查静态语义、真实绘制、几何与可读性、安全和静态格式；不触发事件或测试悬停/点击/导航/播放。涉及动画的参考捕获固定 t=0，不改截图像素来掩盖差异。
- 报告查看器自身的样例切换、缩放和差异图按钮属于研发工具操作，不是 Mermaid 图形交互兼容要求；现有 HTML 报告工具继续使用。
- 像素差仅诊断的既有规则不变；静态漏绘、错关系、错样式或裁剪仍失败。安装验证继续按用户要求暂缓。
