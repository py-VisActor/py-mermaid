## 范围与方法

固定 Mermaid 12.2.0 / `1fb7869866dd619168d840291c9c54b4f129758b`，当前产品 SHA `fe2c293f8ed4ea76e04d34669c8739c27a32063447026e144928bfd6b4ac0bb2`，与上一轮 DSL 及 wheel/sdist 新环境候选相同。保留工作树与全部历史失败；只新增复查资料、原始日志和报告工具。

- 逐项核对39个注册入口（38 Mermaid + 1 VChart）、68个正式 VChart 二维类型及真实 provider 接线。
- 扫描168个 Python 产品文件：没有空函数或 `NotImplementedError`，生产绝对导入只有标准库与既有四个依赖。118个错误防护候选按调用路径区分：非法输入/安全/用户排除/旧切片内部辅助函数不能直接算功能缺口。关键词扫描不构成全分支覆盖。
- 对上一轮22条确认缺口分别复查当前源代码，运行固定来源探针和独立期望断言，保留非零退出、错误消息、源输入、原版结果与当前结果。绿色的“重现已知错误”断言不计修复。
- 2364方法、三后端903组DSL对照、816额外导出及两个Windows新环境安装来自同源码的已闭合上一轮；本轮核验其完整性，不冒称全部重新运行，更不以它们覆盖明确失败的分支。

## 仍需补齐的能力

原22条分支记录分为9个修复簇；记录不是22个独立算法，部分范围有交叉。

| 修复簇 | 分支记录 | 当前仍存在的问题 |
|---|---:|---|
| Cynefin 字符串 | 6 | 合法未知转义、Unicode字面含义、单引号/字面换行等与固定 Langium STRING 转换不同 |
| Architecture 多行元数据 | 1 | 含合法多行元数据的静态服务图被整体拒绝；不要求新增ARIA/交互输出 |
| Gantt 日期解析/格式 | 3 | 浏览器日期fallback、星期、ISO week/hour等源分支缺失 |
| Gantt 轴格式 | 5 | 固定D3 locale、百分号转义、padding和远年ISO行为不等价或报错 |
| Gantt 多周刻度 | 1 | weekday.every 的epoch相位造成日期落点错误 |
| AgentFlow 折叠真实自环 | 1 | 原版保留Outer→Outer，当前模型/路由丢失该边 |
| Sequence 绘制 | 3 | 中央圆偏离lifeline且空心、反向编号遮箭头、自环路径被实心填色 |
| ZenUML 注释 | 1 | 转义星号丢失并误成斜体 |
| ABNF 独立注释行 | 1 | 原版接受，当前解析器拒绝 |

另核实七图表桥的两个既有边界：四个单集合的 Venn 被整体拒绝；Treemap 合法 D3 `valueFormat: ".2s"` 被整体拒绝。原版Venn四个圆/四个标签的实际PNG已看图确认；Treemap补充合法class输入后，原版绿色 `Alpha` 与 `1.0k` 实际可见，当前仍拒绝相同输入。原版默认SI示例的白图缺陷另外保留，未将白图冒作可见对照。这些边界在此前图表接入中已公开，不能因为已写成“限制”就当作原版静态能力完整。合计为原22条记录加2条图表缺口，不是24个独立算法。

另有4条标题/元数据纯值归一差异和EventModeling额外接受原版拒绝的3个输入，单列兼容差异，不伪装成原版正例或额外图种。C4 sprite几何独立控制、部分数值/DST/标签边界及原版组算法运行消费证据仍有限；原生正确接线或源码相似不能直接提升成完整原版等价。供应方全部字段/分支的穷尽审计仍未建立。

## 发布门禁

1. 先修复确认缺口和两个图表输入边界；将独立来源断言纳入发行门禁，清除有源证据推翻的测试期待。测试失败数不直接当作缺口数。
2. 冻结修复后的产品/测试/依赖/资源/README/许可候选，再完成受影响旧回归、三后端实际绘制与静态导出，复核内容/关系/可读性。
3. 同组真实wheel/sdist分别在Windows和Linux干净安装；Windows当前候选已证，Linux py-mermaid候选未证。供应方跨平台通过不能代替消费者验证。
4. 当前版本仍为 `0.0.1a0` / Alpha，工作流只有bootstrap/source校验。正式版本、完整发行CI、发布认证与下载SHA回读尚待实施。PyPI项目接口当前404不证明名称可用或Trusted Publisher已配置，不据此直接上传。

Venn几何来自正式 `py-visactor-vchart` 的公开 `layouts.venn`，当前公开合同本身限制最多三个集合。补齐应在供应方扩展并发布新版本后接入，不在消费者里恢复私有数值算法回退，也不改旧发行资产。Treemap格式限制发生在消费者的格式转换，按固定D3语义补齐。新的统一修复队列见 [final-capability-repair-queue.json](../references/final-capability-repair-queue.json)。

用户本次条件发布授权有效；无需再次确认普通修复或已授权的发布步骤，但只有条件实际满足才能发布。交互、动画、Dagre、video/audio、任意HTML/CSS扩展、3D继续按已有决定排除，不列待补能力。
