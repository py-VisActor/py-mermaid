# py-visactor-mermaid 0.1.1

This documentation release separates library usage from repository maintenance.

- A concise README and PyPI description with installation and a working flowchart example.
- A user documentation index with Python API, CLI, diagram types, offline resources and VChart syntax.
- A separate developer index and a six-section `AGENTS.md` for coding agents.
- The PyPI Documentation URL now points to the user index. Existing session and migration usage links remain as compatibility navigation.

Rendering behavior, supported platforms and dependency constraints remain unchanged. Only the package version changes in runtime source. Archived plans, original images and published 0.1.0 evidence retain their original identities.

```shell
python -m pip install py-visactor-mermaid==0.1.1
```

[User documentation](https://github.com/py-VisActor/py-mermaid/blob/main/docs/README.md) · [English quick start](https://github.com/py-VisActor/py-mermaid/blob/main/docs/user/QUICKSTART.en.md) · [Issues](https://github.com/py-VisActor/py-mermaid/issues)

The release workflow validates the same wheel and sdist on Windows and Linux before uploading. It then verifies actual PyPI file hashes and installs both published distributions again before promoting the GitHub release.
