# py-visactor-mermaid 0.1.2

Adds macOS 13+ support for Apple Silicon and Intel with CPython 3.13. The installer chooses the native Canvas wheel and installs the matching ELK, KaTeX and VChart versions. This supports local static diagrams, math labels and VChart exports from the Python API and CLI.

```sh
python -m pip install py-visactor-mermaid==0.1.2
py-mermaid diagram.mmd --backend cpu -o diagram.svg
```
