# py-visactor-mermaid 0.1.0

Native Python static Mermaid diagrams, using public py-skia-canvas rendering,
py-visactor-elk layout, py-visactor-katex formula drawing and py-visactor-vchart.

The source includes the complete registered Mermaid entrypoint
inventory and the VChart JSON/spec/native DSL integration. The non-chart
closure batch covers string and metadata parsing, ABNF/Zen comments, calendar
formats and intervals, collapsed graph self-loops, and Sequence message paint.
Actual acceptance and release state are recorded in
[the closure plan](https://github.com/py-VisActor/py-mermaid/blob/main/docs/CLOSURE_BATCH_PLAN.md) and execution ledger.

The supported deployment targets are CPython 3.13, Windows AMD64 and Linux
glibc 2.28+ x86_64. CPU installation checks and locally available GPU checks
have separate evidence. Production does not require Node, a browser, a
JavaScript engine or a sibling source checkout.

VChart chart features and existing supplier limits are managed by py-vchart;
this batch does not extend Venn cardinality or Treemap numeric formats.
Interaction, animation, Dagre, video/audio, arbitrary HTML/CSS extensions and
3D are outside the agreed static scope. Normal font and engine differences
are assessed by visible content and relationships rather than cross-engine
pixel identity.

Release assets use a fixed SHA-256 manifest. The publication workflow downloads
the reviewed files, validates the same wheel and sdist on both platforms,
uploads those files, then downloads the actual PyPI files and checks their
hashes before promoting the GitHub release. License texts and source notices
are included in the distributions.


The final static closure is source-bound and locally verified: 132 added contract methods,119 CPU/auto/GPU drawing inputs,255 exports,866 retained inputs and301 DSL cases per backend. Event Modeling also preserves literal data, source entity transport and correct card containment/alignment. Formal artifact/platform and publication evidence is tracked in [closure acceptance](https://github.com/py-VisActor/py-mermaid/blob/main/docs/CLOSURE_BATCH_ACCEPTANCE.md).
