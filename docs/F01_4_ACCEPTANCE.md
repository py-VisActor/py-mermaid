本轮目标是完成固定 Mermaid 12.2.0 的保留静态流程图能力。数学公式作为独立共享模块后续实现；Dagre、交互逻辑及交互元数据已按用户要求排除，安装验证继续暂缓。其他图种不在本轮完成范围内。

## 交付能力

- 保留语法、批量连接、边 ID、metadata、样式级联、方向与别名、子图和初始折叠状态。
- 53 个公开 shape 定义、147 个可达 metadata 别名，以及流程图可达的内部形状入口；普通、富文本和 Markdown 标签。
- ELK 七个顶层入口、来源允许的组算法、13 个公开选项和四个 preset，真实路由、marker、折线整理与跳线；不提供算法回退。
- 确定 seed 的手绘路径与排线，显式离线图片、图标和字体，PNG/JPG/WebP/SVG/PDF 静态导出。
- 标准日志、来源快照、输入与输出指纹、不可变 oracle 复用、CPU/auto/GPU 图片矩阵和离线 HTML 报告。用法见 [F01_4_USAGE](F01_4_USAGE.md)，执行顺序见 [计划](F01_4_EXECUTION_PLAN.md)。

## 验证边界与已知来源行为

语义、实际绘制内容、几何关系、可读性、安全和导出为验收条件；浏览器与 Canvas 的字体栅格、抗锯齿、布局间距和手绘像素差异仅作诊断，不要求逐像素相同。

固定来源存在经典 ellipse 渲染异常，以及 `constructor` 被 JavaScript 原型属性干扰而静默漏画节点的缺陷；它们作为两个独立来源缺陷样例保留，原生端明确拒绝，不返回成功空图。组 `elk.radial` 的来源容器坐标缺陷也单独标记，未伪造正常包围关系。其余组案例严格检查实际包含关系。

无标签小形状按来源不测量隐藏文字；ELK 原始 box 和 routes 原样保存。小形状按来源的首次 anchor 对齐规则使用独立 paint_box，不修改算法输出来掩盖接线问题。datastore 使用虚拟布局外框和真实绘制 parts；开放 brace 路径没有来源未绘制的实体底色。

人工 QA 曾在自动通过的候选中检出状态圆填充、文字阴影、直接 SVG 宿主样式和水平圆柱端盖四类问题。它们的旧图、诊断和针对检查均保留；状态圆检查可检出旧暗圆，圆柱检查会注入旧左端盖作为负控。文字阴影直接绘制有色 glyph；含复合操作的离屏形状阴影先经公开 PNG/Image 入口隔离透明度，再绘制到主 Canvas。直接 SVG 计算宿主样式，img/data URI 资源保持隔离。

资源由调用方明确提供，不在生产运行时抓取网络；缺失或不安全资源明确诊断。数学输入保留为后续模块边界。手绘 seed=0 保留来源随机语义。当前只验收本机 Windows 环境；Linux、无 loader 环境和安装验收未执行。SVG/PDF 为 Canvas 静态输出，不包含 DOM 交互行为。
