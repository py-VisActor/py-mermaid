## 目标与范围

输入 Mermaid 基础流程图，经原生 Python 解析、Canvas 真实文字测量、真实 py-elk 布局与 Canvas 绘制，输出可读 PNG，交付可安装包、调用接口、错误说明、真实示例及验证证据。

本轮支持 `flowchart` / `graph`，TD / LR，矩形和普通文字标签，有向边 `-->`、普通箭头，单节点、链、分支、合流。包括稳定节点/边顺序、必要配置默认值、位置诊断、边界连接与路由、画布包围盒和 padding、PNG bytes/尺寸/MIME、连续调用状态隔离。

边标签、子图、其他形状、HTML/Markdown/math、其他主题/look、Dagre、其他布局算法、手绘、插件与其他导出格式留待后续。范围外输入明确诊断，不默默丢内容或回退。默认 htmlLabels 的普通文字语义映射为 Python 文字排版，不能靠修改该默认值获得通过。

基线：Mermaid 12.2.0 / `1fb7869866dd619168d840291c9c54b4f129758b`；`py-skia-canvas==0.1.0a18` 公开 API；`py-visactor-elk==0.1.0`。CPython 3.13。生产无 Node/browser/JS/.local 依赖；native 对象不跨线程。默认设备策略保留，GPU-required 不得隐式退回 CPU。
