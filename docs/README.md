# py-mermaid 用户文档

中文 | [English](README.en.md)

将 Mermaid 文本或 VChart 图表规格绘制为静态图片。先安装 `py-visactor-mermaid`，然后使用 Python API 或 `py-mermaid` 命令行。

| 要做什么 | 阅读 |
| --- | --- |
| 安装并生成第一张图 | [快速开始](user/QUICKSTART.md) |
| 在 Python、异步程序或命令行中调用 | [API 与 CLI](user/API.md) |
| 选择图种，了解支持边界 | [图种与兼容范围](user/DIAGRAMS.md) |
| 绘制统计图表、地图与组合图 | [VChart 指南](user/VCHART.md) |
| 查完整图表 DSL 语法 | [VChart DSL v1](user/VCHART_DSL.md) |
| 提供字体、图片、图标或数学标签 | [资源与导出](user/RESOURCES.md) |
| 运行更多示例 | [示例目录](../examples/README.md) |

安装环境为 CPython 3.13、Windows AMD64 或 Linux x86_64（glibc 2.28+）。所有输出均为静态图像。当前发行版本见 [PyPI](https://pypi.org/project/py-visactor-mermaid/)，版本说明见 [GitHub Releases](https://github.com/py-VisActor/py-mermaid/releases)。

遇到问题请提交 [Issue](https://github.com/py-VisActor/py-mermaid/issues)，附最小输入、包版本、操作系统、后端和错误信息。

需要修改本项目的开发者和 AI agent，请进入[开发者文档](development/README.md)。会话交接、迁移计划、来源核验和验收日志都归入开发资料，不是使用本库的前置步骤。
