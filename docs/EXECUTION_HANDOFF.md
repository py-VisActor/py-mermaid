# 开发会话交接入口

本页面向维护者和 AI coding agent。使用已发布包请阅读[用户文档](README.md)。

1. 按 [AGENTS.md](../AGENTS.md) 检查 Git 状态并确认当前用户任务。
2. 从[开发者文档](development/README.md)选择相关模块、验证和工具入口。
3. 发行事实见[正式发布记录](MERMAID_PYPI_PUBLICATION.md)和[机器凭据](../references/mermaid-publication-0.1.0.json)；这些记录绑定其原始提交与文件 SHA，不随工作树变化。
4. 查找历史执行细节时再阅读 `docs/execution-state.json`、相关 `docs/changes/` 和验收文件。旧“暂停”“待实现”“未发布”均应按记录时间与候选解释，不能自动恢复旧任务。

旧交接全文[原字节归档](development/history/documentation-before-20261107/docs__EXECUTION_HANDOFF.md.txt)。本次文档整理不重跑或重标旧渲染结果，不改已发布包、tag 或资产。
