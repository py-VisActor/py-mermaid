# py-mermaid user documentation

[中文](README.md) | English

Render Mermaid text or VChart specs as static images. Install `py-visactor-mermaid`, then use Python or the `py-mermaid` command line.

- [Quick start](user/QUICKSTART.en.md): installation, a flowchart, command line and async use.
- [API and CLI](user/API.md) (Chinese): callable signatures, results, errors and command options.
- [Diagram types and compatibility](user/DIAGRAMS.md) (Chinese).
- [VChart guide](user/VCHART.md) and [DSL reference](user/VCHART_DSL.md) (Chinese).
- [Resources and export](user/RESOURCES.md) (Chinese).
- [Runnable examples](../examples/README.md).

Requires CPython 3.13 on Windows AMD64 or Linux x86_64 with glibc 2.28+. Outputs are static. See [PyPI](https://pypi.org/project/py-visactor-mermaid/) and [release notes](https://github.com/py-VisActor/py-mermaid/releases) for published versions.

For bug reports, include a minimal input, package versions, OS, backend and full error in an [issue](https://github.com/py-VisActor/py-mermaid/issues).

Repository maintainers and AI coding agents should use the separate [developer entry](development/README.md). Migration plans and session handoffs are not required to use the library.
